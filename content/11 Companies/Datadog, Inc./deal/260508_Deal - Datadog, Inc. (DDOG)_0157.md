## ② 회사 개요, 제품, 핵심 경쟁력

> [!abstract] 섹션 요약
> Datadog은 현대 클라우드·AI 인프라의 "신경계"다. 기업이 수천 개의 마이크로서비스와 AI 파이프라인을 운영할수록, 이를 관찰하고 보안을 유지하는 Datadog의 가치는 비선형적으로 증가한다.

### 한 줄 설명
**이 회사는 기업의 클라우드·AI 인프라 전체를 실시간으로 모니터링·보안·최적화하는 통합 관찰가능성(Observability) 플랫폼이다.**

### 사업 모델: 어떻게 돈을 버는가?

Datadog의 수익 구조는 **사용량 기반(Usage-Based) SaaS** 모델이다. 고객이 처음에는 인프라 모니터링 하나로 시작하지만, 점점 더 많은 제품을 추가하면서 지출이 자연스럽게 늘어나는 구조다.

- **기반 모델**: 호스트(서버/컨테이너) 수, 로그 데이터 볼륨, APM 서비스 수 등을 기준으로 과금
- **확장 모델**: 초기 인프라 모니터링 → APM → 로그 관리 → 보안 → AI 관찰가능성 순으로 제품 레이어가 쌓임
- **결과**: 고객이 클라우드 규모를 키울수록, AI 시스템을 추가할수록 자동으로 Datadog 지출이 증가 → NRR (Net Revenue Retention) 130%+ 구조

<div style="border-left:4px solid #4CAF50;padding-left:12px;margin:8px 0">
💡 <b>핵심 메커니즘</b>: Datadog 고객이 AWS 비용을 두 배로 늘리면, 모니터링해야 할 인프라가 두 배가 되므로 Datadog 지출도 거의 자동으로 증가한다. AI 에이전트 1개가 추가되면 새로운 모니터링 대상이 수십 개 생긴다.
</div>

### AI 인프라 복잡성 증폭 효과

이것이 Datadog의 가장 강력한 업사이드 비대칭 논거다.

```
AI 에이전트 1개 배포 시 추가되는 모니터링 대상:
- LLM API 호출 (OpenAI, Anthropic, Gemini...)
- 벡터 데이터베이스 (Pinecone, Weaviate...)
- RAG 파이프라인 컴포넌트
- 오케스트레이션 레이어 (LangChain, AutoGen...)
- GPU 인스턴스 모니터링
= 기존 마이크로서비스 대비 10~20배 복잡성
```

기업이 AI에 $1 투자할 때, Datadog에 대한 수요는 **비선형적으로 증가**한다. 이것이 시장이 아직 충분히 반영하지 못한 2차 효과다.
