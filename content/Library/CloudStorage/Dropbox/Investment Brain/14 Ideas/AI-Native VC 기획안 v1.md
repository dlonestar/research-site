# AI-Native VC 전환 기획안

> "The best VCs of the next decade won't be the ones with the most partners — they'll be the ones with the best systems."
> — 이 기획안은 VC 업무 전 과정을 AI로 재설계하여, 심사역 1인의 생산성을 3~5배 높이는 시스템을 제안합니다.

---

## Executive Summary

**문제**: VC 심사역의 업무는 딜소싱부터 사후관리까지 10개 이상의 프로세스가 동시 진행됩니다. 대부분의 시간이 반복적 자료 수집·정리·문서화에 소비되며, 정작 **투자 판단**에 집중할 시간이 부족합니다.

**제안**: 각 업무 단계에 AI 어시스턴트를 배치하여, 심사역이 **"읽고 판단하는 일"에만 집중**할 수 있는 구조를 만듭니다. AI가 80%의 초안·분석·모니터링을 처리하고, 심사역이 20%의 핵심 판단을 내립니다.

**기대 효과**:
| 지표 | 현재 (추정) | AI 도입 후 | 개선율 |
|------|------------|-----------|--------|
| 딜소싱 → 1차 스크리닝 | 주 5시간 | 주 1시간 | 80% ↓ |
| 투자보고서 초안 작성 | 건당 3~5일 | 건당 0.5~1일 | 75% ↓ |
| 포트폴리오사 모니터링 | 월 8시간 | 월 2시간 | 75% ↓ |
| LP 보고서 작성 | 분기당 5일 | 분기당 1일 | 80% ↓ |
| 동시 검토 가능 딜 수 | 3~5건 | 8~15건 | 3배 ↑ |

## 2. 모듈별 상세 설계

### Module 1: AI 딜소싱 엔진 (Deal Sourcing)

> **목표**: "내가 찾는 게 아니라, 딜이 나를 찾아오는 구조"

#### 1-1. 데이터 소스 자동 수집

| 소스 | 수집 내용 | 주기 | 구현 방식 |
|------|----------|------|----------|
| **DIVA (한국벤처캐피탈협회)** | 신규 투자 공시, 펀드 결성 현황 | 매일 | 웹 크롤링 |
| **DART (전자공시)** | 비상장사 공시, 투자 유치 공시 | 매일 | DART API |
| **혁신의 숲 / 스타트업 미디어** | 스타트업 뉴스, 투자 라운드 | 매일 | RSS + Gemini |
| **Crunchbase / PitchBook** | 글로벌 딜 플로우, 라운드 정보 | 매일 | API (유료) |
| **특허청 (KIPRIS)** | 핵심 기술 특허 출원 동향 | 주간 | API |
| **정부 R&D 과제 (NTIS)** | 국가과제 수주 기업 (기술력 시그널) | 주간 | API |
| **LinkedIn / 채용공고** | 핵심 인력 이동, 채용 규모 확대 | 주간 | 웹 스크래핑 |
| **네트워크 유입 (이메일/텔레그램)** | IR 자료, 추천 딜 | 수시 | 파일 드롭 → 자동 파싱 |

#### 1-2. AI 1차 스크리닝

```
입력: 수집된 딜 정보 (기업명, 업종, 라운드, 밸류에이션, 핵심 지표)
     ↓
AI 평가 (5가지 축):
  ① 시장 규모 & 성장성 (TAM/SAM/SOM 추정)
  ② 팀 역량 (창업자 이력, 핵심 인력)
  ③ 제품/기술 차별성 (특허, PMF 시그널)
  ④ 재무 건전성 (번레이트, 런웨이, 유닛이코노믹스)
  ⑤ 당사 투자 적합성 (펀드 전략, 섹터, 스테이지 매칭)
     ↓
출력: 일일 딜 리포트 (Top 3~5, 각 1페이지 요약)
     + PASS 사유 로그 (왜 탈락했는지 기록 → 나중에 재발굴)
```

#### 1-3. 딜 파이프라인 대시보드

```markdown
## 딜 파이프라인 현황

| 단계 | 건수 | 주요 딜 |
|------|-----|---------|
| 🔍 소싱 (Sourcing) | 12 | A사, B사, C사... |
| 📋 검토 (Screening) | 5 | D사, E사... |
| 🔬 실사 (DD) | 2 | F사 (시리즈B), G사 (프리A) |
| 📝 IC 준비 (Memo) | 1 | H사 (투심 4/15 예정) |
| ✅ 집행 (Closing) | 0 | - |

최근 30일: 신규 유입 28건, 검토 진행 8건, IC 상정 1건
전환율: 소싱→검토 29%, 검토→DD 40%, DD→IC 50%
```

### Module 2: AI 실사 어시스턴트 (Due Diligence)

> **목표**: "자료를 넣으면, 분석이 나온다"

#### 2-1. 데이터룸 자동 분석

심사역이 데이터룸(IR자료, 재무제표, 사업계획서 등)을 시스템에 드롭하면:

```
[IR 덱 (PDF/PPT)]  →  AI 구조화 추출:
                        - 시장 규모 주장 vs 실제 데이터 크로스체크
                        - 재무 추정치 합리성 검증
                        - 경쟁사 대비 포지셔닝 분석
                        - 핵심 가정(Assumptions) 리스트업

[재무제표 (Excel)] →  AI 재무 분석:
                        - 매출 성장률 트렌드 & CAGR
                        - 번레이트 & 런웨이 계산
                        - 유닛이코노믹스 (CAC, LTV, Payback)
                        - 동종 업계 벤치마크 대비

[계약서/법률문서]  →  AI 법률 검토 보조:
                        - 주요 조항 요약 (우선주 조건, RCPS 전환)
                        - 리스크 플래그 (희석 방지, 동반매도, 청산우선권)
                        - 과거 유사 딜 조건 비교

[특허/기술문서]   →  AI 기술 분석:
                        - 특허 청구범위 요약
                        - 기술 장벽 수준 평가
                        - 유사 특허·선행 기술 탐색
```

#### 2-2. 레퍼런스 체크 가이드 자동 생성

AI가 DD 과정에서 확인된 리스크를 기반으로:
- 창업자/경영진에게 물어볼 질문 리스트 자동 생성
- 고객사/파트너사 레퍼런스 체크 질문 생성
- 업계 전문가 인터뷰 가이드 생성

#### 2-3. Comparable Analysis 자동화

```
입력: 대상 기업명 + 업종
     ↓
AI가 자동으로:
  ① 국내외 유사 기업 5~10개 선정
  ② 최근 라운드 밸류에이션 매핑
  ③ 주요 지표 비교 테이블 생성 (ARR, GMV, 사용자 수 등)
  ④ 상장사 멀티플 역산 (PSR, EV/EBITDA)
  ⑤ 적정 밸류에이션 레인지 제시
```

### Module 3: AI 투자보고서 생성기 (Investment Memo)

> **목표**: "DD 결과를 넣으면, IC용 보고서 초안이 나온다"

#### 3-1. 표준 투자보고서 구조 (IC Memo Template)

```markdown
# [기업명] 투자검토 보고서
## 작성일: YYYY-MM-DD | 작성자: [심사역명] | AI 보조: Claude

---

### I. 투자 개요 (Executive Summary)
- 투자 구조: [시리즈/금액/지분율/밸류에이션]
- 핵심 투자 근거 (3줄 요약)
- 투자 의견: [투자 추천 / 조건부 추천 / 보류]

### II. 기업 소개
- 회사 개요 (설립, 대표, 임직원 수, 소재지)
- 사업 모델 & 핵심 제품/서비스
- 연혁 & 마일스톤

### III. 시장 분석
- 시장 규모 (TAM → SAM → SOM)
- 시장 성장 전망 & 드라이버
- 규제 환경 & 정책 동향

### IV. 경쟁 분석
- 경쟁 구도 (포지셔닝 맵)
- 핵심 경쟁 우위 & 진입 장벽
- 벤치마크 비교 (Comp Table)

### V. 팀 평가
- 창업자/경영진 프로필 & 트랙레코드
- 핵심 인력 구성 & 리텐션
- 거버넌스 구조

### VI. 재무 분석
- 과거 실적 (3개년)
- 추정 재무제표 (향후 3~5년)
- 유닛이코노믹스
- 자금 사용 계획

### VII. 밸류에이션
- Comparable 분석 (국내/해외)
- DCF / 멀티플 기반 적정가치
- 투자 수익률 시나리오 (Bull/Base/Bear)

### VIII. 투자 구조 & 조건
- 투자 형태 (보통주/우선주/CB/BW)
- 주요 계약 조건
- 펀드 전략 적합성

### IX. 리스크 분석
- 핵심 리스크 (사업/시장/기술/재무/법률)
- 리스크 완화 방안
- Kill Criteria (투자 철회 조건)

### X. 결론 & Action Items
- 최종 투자 의견
- 후속 확인 사항
- IC 논의 포인트
```

#### 3-2. 생성 프로세스

```
Step 1: 심사역이 DD 과정에서 수집한 자료를 시스템에 입력
        (IR덱, 재무제표, 미팅노트, 레퍼런스체크 결과 등)
           ↓
Step 2: AI가 자료 분석 → 각 섹션별 초안 생성
        (Opus 모델 — 깊이 있는 분석 필요)
           ↓
Step 3: 심사역이 초안 리뷰 & 수정
        (핵심 판단, 투자 의견, 컨빅션은 심사역이 직접)
           ↓
Step 4: AI가 최종 포맷팅 & 일관성 검토
        (숫자 검증, 논리 일관성, 오탈자)
           ↓
Step 5: IC용 최종본 출력
        (마크다운 → PDF/PPT 자동 변환)
```

#### 3-3. IC 프레젠테이션 자동 생성

투자보고서에서 핵심 내용을 추출하여:
- 10~15장 슬라이드 구조 자동 생성
- 핵심 차트/그래프 데이터 준비
- 예상 질문 & 답변 가이드 (Devil's Advocate)

#### 4-2. 모니터링 데이터 소스

| **네트워크** | 파트너십, 고객 확보 | 뉴스 + 공시 |

- 최근 분기 실적 요약 자동 생성
- 업계 동향 브리핑 자동 생성  
- 이사회 안건별 검토 의견 초안
- 질문 리스트 자동 생성

### Module 5: Exit 분석 엔진

> **목표**: "최적의 Exit 타이밍과 방법을 데이터로 판단한다"

#### 5-1. Exit 시나리오 분석

```
입력: 포트폴리오사 현재 상태 (재무, 시장, 경쟁)
     ↓
AI 분석:
  ① IPO 시나리오
     - 상장 적합성 평가 (매출/이익 요건, 시장 환경)
     - 예상 공모 밸류에이션 (Comp 기반)
     - 최적 타이밍 (시장 사이클, 업종 모멘텀)
     - 예상 수익률 (IRR, MoIC)

  ② M&A 시나리오
     - 잠재 인수자 리스트 (전략적/재무적)
     - 예상 인수 프리미엄
```

## 7. 경쟁 우위 & 차별화

### "왜 지금, 우리가?"

```
1. 기술 성숙도
   - GPT-4/Claude Opus 수준의 모델이 투자 분석 품질을 처음으로 실용 수준에 도달
   - 2024~2025년에는 불가능했던 것이 2026년에 가능해짐

2. 선점 효과
   - 국내 VC 중 AI 시스템을 체계적으로 구축한 곳은 아직 극소수
   - 1~2년 내 구축하면 데이터 축적에서 후발 주자 대비 구조적 우위

3. 축적의 힘 (Compounding)
   - 검토한 딜이 쌓일수록 → 스크리닝 정확도 향상
   - 투자 결과가 쌓일수록 → 의사결정 모델 개선
   - 시장 데이터가 쌓일수록 → 밸류에이션 벤치마크 정교화
   - 시간이 지날수록 경쟁 우위가 자동 확대되는 구조

4. 개인 투자 시스템 경험
   - Investment Brain으로 6개월+ 운영한 파이프라인 아키텍처 검증 완료
   - 동일 기술 스택(Python, Claude, Gemini, Obsidian, PM2) 재활용 가능
   - 시행착오를 이미 거쳤으므로 VC 버전은 훨씬 빠르게 구축 가능
```

### 업계 벤치마크

## 9. 결론

### AI-Native VC로의 전환은 선택이 아닌 필수입니다.

**핵심 메시지**:
1. AI는 심사역을 대체하는 것이 아니라, **심사역의 판단력을 극대화**하는 도구입니다
2. **80%의 반복 업무를 AI가 처리**하면, 심사역은 정말 중요한 **20%의 판단에 집중**할 수 있습니다
3. 월 27만원의 비용으로 **13배 이상의 ROI**를 기대할 수 있습니다
4. 데이터가 쌓일수록 시스템이 자동으로 진화하는 **축적의 구조**입니다
5. 지금 시작하면 **1~2년의 선점 효과**를 확보할 수 있습니다

### 제안: Phase 0~1부터 시작 (4~6주)

대규모 투자 없이, 기존 인프라를 활용하여 **딜소싱 자동화**부터 시작합니다.
Quick Win으로 효과를 증명한 뒤, 단계적으로 확장합니다.
